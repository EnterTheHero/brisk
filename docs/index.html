Brisk

Brisk is a small, private web browser for Windows and Mac, built on Chromium. It blocks ads and trackers, keeps a clean look, and supports Chrome Web Store extensions, profiles and tab groups.

Sync with Google Drive

Brisk can keep your bookmarks and settings the same on all your computers. It does this by saving one small file in the hidden app folder of your own Google Drive. There is no Brisk server; nothing is sent to anyone else.
